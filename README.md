# Occupancy Tracker

    A responsive browser-based occupancy tracking app built with HTML, CSS, and JavaScript.

## Features

- Increment and decrement the current occupancy count
- Save completed occupancy entries
- Persist saved entries with browser `localStorage`
- Restore saved entries after refreshing the page
- Reset the current count and saved history
- Responsive layout for desktop and mobile screens
- Accessible live status updates and keyboard focus states

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage API
